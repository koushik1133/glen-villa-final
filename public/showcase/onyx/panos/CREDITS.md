# Interior panoramas — attribution and status

These five equirectangular panoramas are **CC0 (public domain) HDRIs from Poly Haven**
(https://polyhaven.com), tonemapped and re-encoded to 4096x2048 WebP:

| File | Poly Haven source |
|---|---|
| living.webp | lebombo |
| dining.webp | cayley_interior |
| bedroom.webp | hotel_room |
| kitchen.webp | brown_photostudio_04 |
| balcony.webp | hotel_rooftop_balcony |

**They are representative interiors, not photographs of a Glentree Onyx apartment.**
The UI must label them that way wherever they are shown. Replace them with the
project's own 360 captures (same filenames, 2:1 equirectangular) when those exist,
and the labelling can then be dropped.

CC0 imposes no attribution requirement; this file records provenance so nobody
later mistakes these for the client's own photography.
